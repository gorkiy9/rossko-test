# Выбор курьера — тестовое задание и прототип

Сайт с презентацией тестового: текст задания и кликабельный прототип оформления заказа, переключаются сегментами в шапке.

- `index.html` → `src/presentation` — презентация (текст задания, оглавление, схема, состояния A–E со ссылками в прототип)
- `prototype.html` → `src/main.tsx` — сам прототип: корзина, оформление, трекинг, оценка
- `courier-prototype-handoff/` — спецификация, правила и чек-лист приёмки

Презентация собрана на токенах (`src/index.css`) и компонентах прототипа (`Segmented`, `r-card`, `r-btn`, `r-courier`…).

## Запуск

```bash
npm install
npm run dev
```

Хостинг — GitHub Pages, деплой из `main` через `.github/workflows/pages.yml`.
