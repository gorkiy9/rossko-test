# Чек-лист приёмки

Проверяется на `npm run dev`. Каждый сценарий открывается по ссылке `/#/checkout?s=X` и через панель «Сценарий» на странице оформления. Ширины: 375, 768, 1024, 1440 px.

## Сценарий A — «Кофемашина»

Корзина: кофемашина рожковая 34 990 ₽, кофе в зёрнах 1 290 ₽. Слот — завтра, 19:00–21:00.

- [ ] Умный (Алексей) предвыбран.
- [ ] Бейдж «Рекомендуем для вашего заказа» и причина: «В заказе кофемашина — курьер подключит её и покажет первый капучино».
- [ ] На карточке умного 3 услуги: «Подключит кофемашину и проверит работу», «Покажет, как приготовить первый капучино», «Проверит товар при вас».
- [ ] Красивый (Марк) виден рядом в том же размере, «+199 ₽»; премиум (Ника) — компактной строкой, «+499 ₽».
- [ ] Итог 36 280 ₽, кнопка «Оплатить 36 280 ₽».
- [ ] Подтверждение «Отлично, Алексей подключит кофемашину».
- [ ] Строка «Курьер «Умный»» в сводке — «Бесплатно».

## Сценарий B — «Канцелярия»

Корзина: блокнот А5 390 ₽, набор гелевых ручек 250 ₽.

- [ ] Ничего не выбрано, бейджа нет, у умного общие услуги.
- [ ] В сводке «Курьер — не выбран».
- [ ] Нажатие «Оплатить 640 ₽» не уводит со страницы: блок курьера подсвечен, ошибка «Выберите, кто привезёт заказ», страница прокручена к блоку.
- [ ] После выбора любого типа ошибка уходит, итог пересчитан, оплата проходит; для умного подтверждение «Отлично, Алексей проверит заказ при вас».

## Сценарий C — «Нет красивых сегодня»

Корзина как в A, слот сегодня 19:00–21:00.

- [ ] Слот «сегодня, 19:00–21:00», умный предвыбран, итог 36 280 ₽.
- [ ] Карточка красивого неактивна, но видна, с пометкой «Нет свободных на это время».
- [ ] Текст «Ближайший свободный слот: завтра, 14:00–16:00» и кнопка «Выбрать этот слот».
- [ ] Премиум «Красивый и умный» на текущем слоте остаётся доступным для выбора.
- [ ] Клик по кнопке меняет слот на «завтра, 14:00–16:00», карточка красивого становится активной и выбранной, итог 36 479 ₽.
- [ ] Новый слот отображается в сводке «Ваш заказ» и на трекинге.

## Сценарий D — «Повторный»

Корзина: кроссовки беговые 6 490 ₽, есть история с умным.

- [ ] Умный предвыбран, бейдж и причина «В заказе обувь — курьер подождёт, пока вы примерите».
- [ ] Услуги: «Подождёт примерку», «Сразу заберёт то, что не подошло», «Проверит товар при вас».
- [ ] Итог 6 490 ₽.
- [ ] Под карточкой умного строка: «В прошлый раз курьер настроил вам телевизор».
- [ ] При выборе красивого подсказка «Вернуть неподошедшее можно в пункте выдачи».

## Сценарий E — «Выбран красивый»

Корзина как в A, выбран красивый.

- [ ] Выбран красивый, итог 36 479 ₽.
- [ ] Под карточками спокойная подсказка: «С подключением поможет инструкция в коробке».
- [ ] Подтверждение «Отлично, Марк привезёт заказ в подарочной упаковке».
- [ ] Никаких модалок и всплывающих предупреждений.

## Сквозные требования

### Выбор и цены
- [ ] Смена курьера — один клик; цена в сводке и итог обновляются сразу.
- [ ] После каждого выбора — подтверждение с именем курьера; для премиума — «Отлично, Ника поможет с товаром и привезёт его в подарочной упаковке», итог +499 ₽.
- [ ] Смена сценария сбрасывает выбор к исходному для нового сценария.
- [ ] Выбранный курьер и итог одинаковы на оформлении, трекинге и оценке.
- [ ] На оценке вопрос о пользе зависит от курьера: умный и премиум — «Курьер помог с товаром?», красивый — «Понравилась встреча и упаковка?».

### Навигация
- [ ] Флоу проходится кнопками: «Перейти к оформлению» → «Оплатить N ₽» → «Заказ получен» → «Отправить оценку».
- [ ] Из оформления можно вернуться в корзину ссылкой «Изменить», выбор курьера и слота сохраняется.
- [ ] `?s=` и панель «Сценарий» переключают сценарии; панель не перекрывает основные кнопки.
- [ ] Старые адреса `#/address`, `#/slot`, `#/courier`, `#/payment` ведут на оформление.

### Доступность
- [ ] До карточек можно дойти Tab, выбрать Space/Enter.
- [ ] Карточки — `role="radio"` + `aria-checked` внутри `role="radiogroup"`.
- [ ] Подтверждение выбора в `role="status"`, ошибка без курьера — в `role="alert"`.
- [ ] Фокус видим на всех интерактивных элементах.

### Адаптив
- [ ] Нет горизонтального скролла на 375–1440 px.
- [ ] ≥ 960 px — сводка справа с кнопкой оплаты; < 960 px — одна колонка и нижняя панель с итогом и кнопкой.

### Документация
- [ ] Тексты и данные сценариев в `../src/data.ts` совпадают с разделом «Тексты интерфейса» spec.md.
- [ ] Изменения интерфейса в проде отражены в spec.md.

### Запреты
- [ ] Нет подтверждающих модалок, ложного дефицита, скрытого красивого курьера.
- [ ] Нет текстов и цен вне spec, новых брендов и логотипов.
- [ ] `npm run build` и `npm run lint` без ошибок.
